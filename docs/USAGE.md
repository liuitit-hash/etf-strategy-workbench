# 使用说明

一句话：这是**约束你自己**的工具——记录交易、隔离浮盈与落袋、用三框架校验每笔操作是否违背你自己定的纪律。
它**不预测涨跌、不荐股**。

## 日常动线
1. **① 先去「策略」页写死规则**（只需做一次，之后很少改）：
   - 加标的，绑定框架（芒格/达利欧/格雷厄姆），标能力圈、黑名单（如军工=禁加仓）。
   - 设格雷厄姆档位：回撤 X% → 允许加仓 Y 元；设单标的上限、冷却期。
   - 设止盈：目标价/目标收益率、分批比例。
   - 设子弹总预备金 + 各标的加仓额度。
   > 这套规则就是"基准契约"，之后所有校验、简报都拿它当唯一标准。频繁改档位本身就是一种情绪化，慎改。

2. **② 每次成交后去「录入」页记流水**：
   - 填时间、标的、买卖、份额、单价、费用；港股通标的会多一个"成交汇率"。
   - 选操作标签：按策略触发 / 情绪化提前 / 计划内止盈。
   - 录入时下方会**即时预检**是否违反纪律（未到档位加仓、超额、冷却期内、黑名单加仓、未达止盈就卖……）。
   - 流水**不可删除**，只能加"备注更正"——这是防止你事后粉饰。

3. **③「看板」看绩效**（最常看）：
   - **绿色块=累计已兑现收益**（确定落袋，不随行情变）；**黄色块=账面浮动盈亏**（会消失，不能作为操作依据）。两者强制分开。
   - 总投入、市值、MWR(资金加权)、策略执行率、子弹储备、分标的独立台账。

4. **④「简报」读三类复盘**（后台定时生成，读它不花钱）：
   - 盘前：外围+宏观周期标签+估值校验+距档位+风险清单+纪律提醒。
   - 盘中：一次性快照，不高频。
   - 盘后：六维完整复盘，含驱动归因、框架打分、绩效与执行率、下一日"操作预案"（只复述你写死的规则）。
   - 每篇可一键复制 Markdown，底部强制挂免责声明。

5. **⑤「数据」看抓取到的估值/宏观/新闻**；**⑥「回溯」**任选历史某天看当时简报与结论，检查策略是否失效。

## 两个纪律提醒
- 看到账面浮盈别飘、浮亏别慌——看板已把它和"落袋"隔开，就是为了让你盯确定的那一块。
- 简报里的"操作预案"永远只是你自己规则的回放，它不会、也被禁止给你任何新建议或涨跌预测。

## 临时想要一份复盘
页面本身不调用大模型（省钱）。需要即时复盘时：GitHub → Actions → **briefings** → Run workflow → 选类型 + 勾 force。
几十秒后在「简报」页刷新即可。
